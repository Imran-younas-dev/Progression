# First release is the execution engine

The vision doc treats a life-goal engine and a career workspace as one first release. We will ship the engine first: goals, milestones, tasks, Today, and a weekly review. Career tools wait until people return in later weeks.

A resume builder, application tracker, and interview bank are each large enough to hide whether the core habit works. Category stays a label on the goal so Career can be added later without changing what a goal is.
