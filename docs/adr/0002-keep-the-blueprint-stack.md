# Keep the blueprint stack

The vision doc names Next.js and a TypeScript Nest API. This repository is already the setup blueprint: a JavaScript Nest API, a React and Vite web app, MySQL, and Redis. We keep that stack.

The blueprint is the structure we set up to build on, and the app here has no existing career data to migrate. Switching the UI to Next.js or rewriting the API in TypeScript would restart the scaffold before the product exists.
